# 💾 nicknamemaker

**nicknamemaker**는 Windows 95 스타일로 디자인된 이름 짓기 웹사이트입니다. 이 사이트는 사용자가 새로운 이름을 생성하거나 자신의 이름을 입력하여 ID 카드를 만들 수 있도록 도와줍니다. 레트로한 느낌을 주는 이 사이트는 과거의 추억을 불러일으키면서도 새로운 사용자에게도 즐거움을 제공합니다.
**nicknamemaker** is a name-generating website designed in the style of Windows 95. This site allows users to create new names or input their own names to generate ID cards. With a retro feel, this site evokes nostalgia while providing enjoyment for new users as well.

## 소개 (Introduction)

**nicknamemaker**는 Windows 95의 컴퓨터 느낌을 살린 웹 프로젝트로, 컨트롤 바와 스타트 버튼을 통해 메뉴를 탐색할 수 있습니다. 사용자는 이름 짓기 기능을 활용하여 새로운 이름을 생성하거나, 자신의 이름을 입력하여 새로운 ID 카드를 생성할 수 있습니다.
**nicknamemaker** is a web project that captures the essence of a Windows 95 computer, complete with a control bar and a Start button for navigating menus. Users can take advantage of the name-generating feature to create new names or enter their own names to generate new ID cards.

## 기능 (Features)

- **이름 짓기(Name Generation)**: 랜덤 이름 생성기 기능을 통해 다양한 이름을 생성합니다. (Generate a variety of names using the random name generator feature.)
- **ID 카드 생성(ID Card Creation)**: 사용자가 입력한 이름을 바탕으로 ID 카드를 만들 수 있습니다. (Create ID cards based on the name entered by the user.)
- **공유 및 다운로드(Sharing and Downloading)**: 생성된 이름이나 ID 카드를 이미지로 다운로드하여 공유할 수 있습니다. (Download and share the generated names or ID cards as images.)
- **로컬 저장(Local Storage)**: 생성된 ID 카드는 로컬 스토리지에 저장되어 삭제하지 않는 한 계속 사용할 수 있습니다. (Generated ID cards are stored in local storage, allowing continued use until deleted.)
- **다양한 용도(Versatile Usage)**: 게임 캐릭터, 인스타그램 ID, 동식물 이름 등 다양한 용도로 활용할 수 있습니다. (Useful for generating names for game characters, Instagram IDs, and names for animals or plants.)


## 시작하기 (Getting Started)

웹사이트에 접속하려면 아래 링크를 클릭하세요: 
To access the website, click the link below:

[https://nwewave32.github.io/nicknamemaker/](https://nwewave32.github.io/nicknamemaker/)

브라우저에서 바로 실행 가능하며, 별도의 설치가 필요하지 않습니다.
No installation is required, and it can be run directly in your browser.

## 사용 방법 (How to Use)

1. 링크를 통해 사이트에 접속합니다. Access the site through the link.
2. 스타트 버튼을 클릭하여 Windows 95 스타일의 메뉴를 엽니다. Click the Start button to open the Windows 95-style menu.
3. "이름 짓기" 옵션을 선택하여 랜덤 이름을 생성합니다. Select the "Name Generation" option to generate random names.
4. 자신의 이름을 입력하여 ID 카드를 생성합니다. Enter your own name to create an ID card.
5. 생성된 ID 카드는 이미지로 다운로드하거나 공유할 수 있습니다. The generated ID card can be downloaded as an image or shared.
6. 로컬 스토리지를 통해 생성된 ID 카드가 저장됩니다. Generated ID cards are saved through local storage.
